## roles

1. naming
    - llm에게 작성시킨 문서는 `*_llm.md`
    - 직접 작성한 문서는 `*.md`

2. 작성
    - 실행 가능한지 검증하며 작성할 것
        - 단순 참고는 링크걸면 된다
        - 레퍼런스 문서로 내재화하는 이유를 상기하자


---

- expanded ascii tool box

```ascii
[기본 실선 / 단선 (Light)]
┌ ┬ ┐   ┌─┬─┐
├ ┼ ┤   │ │ │
└ ┴ ┘   └─┴─┘
선: ─ │

[굵은 실선 (Heavy)]
┏ ┳ ┓   ┏━┳━┓
┣ ╋ ┫   ┃ ┃ ┃
┗ ┻ ┛   ┗━┻━┛
선: ━ ┃

[이중선 (Double)]
╔ ╦ ╗   ╔═╦═╗
╠ ╬ ╣   ║ ║ ║
╚ ╩ ╝   ╚═╩═╝
선: ═ ║

[둥근 모서리 (Rounded)]
╭ ┬ ╮   ╭─┬─╮
├ ┼ ┤   │ │ │
╰ ┴ ╯   ╰─┴─╯

[단선 + 이중선 혼합 분기점]
╒ ╤ ╕  ╓ ╥ ╖
╞ ╪ ╡  ╟ ╫ ╢
╘ ╧ ╛  ╙ ╨ ╜

[화살표 및 포인터]
삼각 채움: ► ◄ ▲ ▼
삼각 빈칸: ▷ ◁ △ ▽
선 화살표: → ← ↑ ↓ ↔ ↕
이중 화살표: ⇒ ⇐ ⇑ ⇓ ⇔

[체크 / 불릿 / 상태 기호]
블록: █ ▓ ▒ ░ ■ □ ▣ 
원형: ● ○ ◐ ◑ ◈ ◇ ◆
체크: ✔ ✖ ✕ ✗ 
```

- 집합 포함관계 기호
```
부분집합 (진부분집합): ⊂ / ⊃
예시: unit ⊂ widget ⊂ integration
부분집합 (동등 포함 가능): ⊆ / ⊇
부분집합 아님: ⊄ / ⊅
원소 기호: ∈ / ∋ / ∉
합집합 / 교집합: ∪ / ∩
```
