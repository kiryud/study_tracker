# Study Tracker 기획서

## 1. 프로젝트 개요

### 1.1 프로젝트명
- **가칭:** Study Tracker
- **부제:** 꾸준함을 시각적으로, 놓치는 과목 없이 꼼꼼하게

### 1.2 개발 배경
개인 학습 과정에서 여러 분야와 과목을 병행하다 보면 과목별 학습 시간, 학습 이력, 목표 일정 및 복습 시점을 개별 도구나 수동 기록(엑셀 등)으로 각각 관리해야 하는 불편함이 발생했습니다.

기존에는 내가 언제 무엇을 공부했는지 통합적으로 파악하고 관리할 수 있는 하나의 도구가 없었으며, 특히 태블릿으로 필기 앱이나 인터넷 강의를 띄워놓고 공부할 때 분할 화면(Multi-window) 환경까지 쾌적하게 지원하는 학습 관리 앱이 부족했습니다.

이에 학습 계획(Planner), 시간 측정(Time Tracker), 복습 주기 관리(Reminder), 학습 현황 시각화(Dashboard)를 하나의 애플리케이션에서 유기적으로 관리할 수 있는 서비스를 기획하였습니다.

### 1.3 프로젝트 목적
개인의 학습 활동을 계획부터 측정, 기록, 복습까지 체계적으로 통합 기록하고 시각화하여 지속 가능한 학습 습관과 관리 환경을 제공하는 것을 목적으로 합니다.

### 1.4 프로젝트 목표
- 분야·과목·단원 및 계획과 연계된 다계층 학습 시간 측정 및 이력 관리
- 고정 일정과 유동적인 학습 계획을 아우르는 플래너 및 목표일(D-day) 관리
- 학습 기록 기반 복습 시점 계산 및 누적형(Stacking) 알림 제공
- `1x1`, `2x1` 위젯 카드 기반의 직관적인 학습 현황 대시보드 제공
- 스마트폰 및 태블릿(가로/세로, 전체 화면·3분할 화면·팝업창) 반응형 UI/UX 지원
- 오프라인 우선(Offline-first) 환경 지원 (SQLite 기반 기기 내 데이터 즉시 저장)
- 사용자 계정(`UUIDv7` 식별자) 기반 다중 사용자 로컬 DB 파일 분리(`guest.db`, `user_{UUID}.db`) 및 기기 간 백업·연동

### 1.5 기술 스택 및 개발 환경 (Tech Stack)

#### 클라이언트 (Frontend)
- **프레임워크 / 언어:** Flutter (Dart)
- **타겟 플랫폼:** Android (스마트폰 및 태블릿 지원, Material Design 3 기반)
  - *미지원:* iOS / iPadOS (`Cupertino` 미사용), *추후 확장 고려:* Web / Desktop
- **아키텍처 및 주요 모듈:**
  - **상태 관리 및 DI:** `flutter_riverpod` (`ProviderScope` 기반 전역 및 Feature별 프로바이더 구성)
  - **라우팅:** `go_router` (`AppPage` enum 기반 선언적 라우팅)
  - **로컬 데이터베이스:** `sqflite` (SQLite 기반 오프라인 저장소, `guest.db` 및 `user_{UUIDv7}.db` 파일 분리)
  - **보안 스토리지:** `flutter_secure_storage` (서버 발급 인증 토큰 및 세션 정보 암호화 저장)
  - **백그라운드 및 알림:** `flutter_foreground_task`(백그라운드 타이머 유지), `flutter_local_notifications`(상단바 타이머 상태 표시 및 복습 푸시 알림)
  - **식별자 생성:** `uuid` (`UUIDv7` 기반 시간순 정렬 가능 고유 식별자)
  - **추후 확장 검토 모듈:** `home_widget` (안드로이드 홈 화면 위젯 연동)
- **레이아웃 디렉토리 구조 (`lib/`):**
  - `app/` (`theme`, `router`, `config`)
  - `core/` (`enum`, `extensions`, `models/result.dart`)
  - `feature/` (`remote` API 통신 서비스·프로바이더 / `local` SQLite CRUD 서비스·프로바이더)
  - `models/` (데이터 클래스)
  - `ui/` (`pages`, `widget/common`, `widget/dashboard`)

#### 백엔드 및 인프라 (Backend & Infra)
- **아키텍처:** Monolithic 3-Tier API Server (`User Service` + `SQLite Backup Data Service`)
  - 핵심 학습 데이터 연산 및 조회는 클라이언트 내부 SQLite에서 처리하며, 백엔드 서버는 **사용자 인증(계정 관리)**과 **사용자별 SQLite `.db` 파일 백업·복원 및 메타데이터 관리**에 집중한다.
- **서버 환경:**
  - **본 서버:** Docker Compose 기반 (Nginx - Spring Boot (Java, Gradle) - PostgreSQL)
  - **임시 API 서버 (개발 및 테스트용):** FastAPI(Python) 또는 ASP.NET Core Minimal API(C#) 기반 경량 컨테이너 서버 (`:8080`, `/api/v1/*`)
- **인증 방식:**
  - 자체 회원가입/로그인 (`id`, `nick`, `pw` 기반 가입 및 `UUIDv7`, `nick` 반환 / JWT 발급)
  - OAuth 2.0 / OIDC 기반 소셜 로그인 확장 고려

## 2. 현황 및 문제 정의

### 2.1 기존 학습 관리 방식의 문제점 및 타 서비스 한계
- 학습 시간 측정(타이머), 과목별 기록, 일정 관리, 복습 주기를 별도의 앱이나 수동 기록(엑셀 등)으로 각각 관리해야 하여 학습 정보가 분산된다.
- 시중 학습 앱(열품타 등)은 단순 타이머와 소셜/경쟁 기능에 치중되어 있어, 개인의 학습 계획부터 세부 기록·누적 복습까지 하나로 이어지는 통합 관리가 어렵다.
- 태블릿으로 강의 시청이나 필기 앱을 띄워놓고 공부할 때, 안드로이드 태블릿의 분할 화면(2분할·`├`형 3분할)이나 팝업창 크기에 맞춰 자연스럽게 동작하는 적응형(Adaptive) 학습 앱이 부족하다.
- 네트워크가 없는 환경에서의 독립적인 사용성과 스마트폰 ↔ 태블릿 간 데이터 이어쓰기가 동시에 충족되지 못하는 경우가 많다.

### 2.2 해결 방향 및 본 앱의 특장점 (차별화 포인트)
- **계획-측정-복습-시각화의 유기적 통합 (All-in-One):** 플래너에서 세운 계획을 타임 트래커로 측정하고, 그 기록을 바탕으로 복습 리마인더를 등록하며, 대시보드 위젯으로 한눈에 통계를 확인하는 선순환 구조를 제공한다.
- **태블릿 및 멀티윈도우 특화 반응형 UI/UX:** 기기 물리 해상도가 아닌 **현재 앱 창에 할당된 논리 픽셀(`dp`) 너비(`600dp`, `840dp` 분기)**를 기준으로 스마트폰 세로·가로, 태블릿 전체 화면, 태블릿 분할 화면 및 팝업창까지 모두 깨짐 없이 대응한다.
- **오프라인 우선(Offline-first) 및 파일 단위 DB 격리·백업:** 모든 학습 기능은 로컬 SQLite(`guest.db` 또는 `user_{UUIDv7}.db`)에서 즉시 동작하며, 계정 연동 시 SQLite 파일 단위로 깔끔하게 격리 및 백업·동기화한다.
- **확장 가능한 데이터 설계:** 기본 플래너와 대시보드 위젯을 직관적인 표준 UI로 우선 제공하되, 축적된 다계층 데이터를 기반으로 향후 엑셀 스타일의 정사각형 그리드 현황판(좌측 연·월·요일 9칸 고정 + 상단 분류 고정) 등 고도화된 커스텀 뷰로 손쉽게 확장할 수 있도록 데이터를 설계한다.

## 3. 서비스 정의

### 3.1 서비스 소개
Study Tracker는 개인의 학습 계획, 시간 측정, 복습 주기 및 학습 통계를 한곳에서 기록하고 관리하는 안드로이드(스마트폰·태블릿) 학습 관리 애플리케이션입니다.

### 3.2 핵심 가치
- `기록:` 계획 유무와 관계없이 모든 학습 활동을 다계층 구조로 꼼꼼하게 기록한다.
- `시각화:` 축적된 학습 데이터를 대시보드 위젯을 통해 직관적으로 확인한다.
- `관리:` 고정 일정과 목표 일정(D-day), 누적 복습 주기를 체계적으로 관리한다.
- `지속성:` 대시보드 최상단 동기부여 문구와 알림을 통해 꾸준한 학습을 유도한다.
- `접근성:` 네트워크 연결 여부나 화면 분할 상태에 구애받지 않고 언제든 학습 기능을 이용한다.

### 3.3 주요 사용자
스마트폰과 태블릿을 병행하며 개인의 학습 활동을 체계적으로 기록·관리하고자 하는 사용자.

## 4. 주요 기능 정의

### 4.1 대시보드 (Dashboard)
앱 진입 시 학습 현황을 종합적으로 확인하는 메인 화면이다.

- **내가 공부하는 이유 (동기부여 고정 영역):**
  - 대시보드 최상단에 1~2줄 높이의 짧은 배너/카드 형태로 항상 노출되어 앱 입장 시 목표 의식을 환기한다.
- **모듈형 대시보드 위젯 (`1x1`, `2x1` 규격):**
  - 화면의 `dp` 폭에 따라 열 개수가 유동적으로 배치되는 반응형 그리드 구조를 가진다.
  - **From Time Tracker:** 과목별·분야별 누적 학습 시간 및 최근 학습 주기 통계 위젯
  - **From Planner:** 목표일(D-day) 및 오늘 예정된 할 일(To-do) 요약 위젯
  - **From 복습 Reminder:** 오늘 수행해야 할 복습 및 지연·누적된 복습 요약 위젯
- *(향후 확장 뷰)* 축적된 데이터를 기반으로 좌측(`연/월/월~일` 9칸)과 상단(`분류`)이 고정된 정사각형 그리드 기반 커스텀 학습 이력 현황판 추가 가능

### 4.2 플래너 (Planner)
학습 목표와 일정을 4단계 시퀀스(`일정 범위 설정 → 분야·주제별 계획 → 실행·측정 연계 → 결과 관리`)로 관리하는 기능이다.

- **일정 및 유효 범위 설정:**
  - 시험 기간, 학사 일정, 프로젝트 기간, 분기/반기/연간 등 특정 기간의 고정 일정 등록
  - 수면, 식사, 운동 등 개인 생활 루틴 및 알바·업무 등 고정 패턴 일정 관리
- **분야 및 주제별 계획 관리:**
  - 목적(전공, 시험, 어학, 업무, 취미 등)에 따른 분야 분류 및 관리할 세부 주제 설정
  - 목표일 기준 D-day 관리 및 일일·주간 To-do 계획 등록
- **기록 및 복습 연계:**
  - 등록된 계획은 타임 트래커(시간 측정) 및 복습 리마인더 생성과 직접 연동
  - 사용자가 별도 학습 없이 바로 적응할 수 있는 직관적인 표준 플래너 UI 제공

### 4.3 타임 트래커 (Time Tracker / 타이머)
학습 시간을 다계층으로 측정하고 기록하는 기능이다.

- **다계층 학습 기록 구조:**
  - `전체 학습 시간 / 분야 / 과목 / 단원 / 세운 계획`의 다계층 통계를 산출할 수 있으면서도, 사용자가 이를 중복 입력·관리하는 번거로움이 없도록 단일 흐름으로 기록한다.
- **지원 측정 케이스:**
  1. **계획 연동 측정 (`with plan`):** 플래너에 등록된 특정 분야·주제의 계획을 선택하여 학습 시간 측정 및 기록
  2. **자유 측정 (`without plan`):** 사전 계획 없이 즉시 분야·과목을 선택하여 학습 시간 측정 및 기록
  3. **직접 입력:** 타이머를 켜지 않고 공부한 시간을 사후에 직접 입력하여 기록
  4. **시험/모의고사 모드 (커스텀 프리셋):** 수능 등 과목별 제한 시간이 다른 시험 환경에 맞춰 사용자가 시간 구성을 커스터마이징하여 측정
- **타이머 조작 및 화면 형태:**
  - 일시정지, 조기 종료, 시간 추가, 무제한(스톱워치) 측정 지원
  - 아날로그 형태(뽀모도로 원형 시계) 및 디지털 형태(기계식/LED 시계) 지원 및 배터리 소모 최소화 지향
  - **전체 화면 시계 모드:** 특정 버튼 클릭 시 현재 앱 창(전체 화면 또는 분할 화면 영역)을 가득 채우는 시계 뷰 전환
- **백그라운드 실행 및 알림바 제어:**
  - 다른 앱(필기 앱, 강의 앱) 사용 중이거나 화면이 잠긴 상태에서도 `Foreground Service`를 통해 끊김 없이 시간 측정 유지
  - 기본 시계 앱처럼 상단 상태바 및 알림창(Notification), 잠금화면에서 진행 시간 확인 및 제어 가능

### 4.4 복습 리마인더 (복습 알림이)
학습한 내용을 잊지 않도록 복습 주기를 계산하고 알려주는 독립 페이지 및 알림 기능이다.

- 학습 기록(Time Tracker) 및 계획(Planner)을 기반으로 복습 대상 등록 및 예정일 계산
- 지정된 복습 시점에 푸시 알림(`flutter_local_notifications`) 제공
- **누적(Stacking) 표시 시스템:**
  - 예정된 복습을 완료하지 않으면 목록에서 사라지지 않고 누적되어 표시
  - 누적량 및 지연 일수에 따라 단계별 색상(경고도)을 다르게 표기하여 우선순위 인지 지원

### 4.5 동기부여 문구 및 대시보드 설정
- 기본 명언 모음집 제공 및 사용자가 직접 입력하는 '내가 공부하는 이유' 문구 등록·수정
- 상단 메뉴(`=` 또는 `⋮`) → 설정(또는 대시보드 설정)에서 동기부여 문구 및 대시보드 위젯 구성을 관리

### 4.6 사용자 서비스 (Auth & Backup)
사용자 계정을 관리하고 기기 간 데이터를 연동하는 기능이다.

- **회원가입 (`POST /api/v1/auth/signup`):** `id`, `nick`, `pw`를 입력받아 중복 검사 후 계정 생성 (`UUIDv7` 발급 및 `nick` 반환)
- **로그인 (`POST /api/v1/auth/login`):** `id`, `pw` 검증 후 해당 유저의 고유 `UUIDv7` 식별자 및 `nick`(추후 JWT 포함) 반환
- **게스트 모드 지원:** 로그인 없이 즉시 앱 사용 가능 (`guest.db` 사용)
- **계정별 데이터 백업 및 기기 간 연동:** 사용자 고유 `UUIDv7`을 기준으로 로컬 SQLite DB 파일(`user_{UUIDv7}.db`)을 분리 관리하며, 서버 백업 서비스를 통해 여러 기기(스마트폰 ↔ 태블릿) 간 데이터를 동기화

## 5. 사용자 시나리오

### 5.1 최초 이용 (게스트 또는 회원가입)
1. 사용자가 앱을 설치하고 실행한다.
2. 로그인 화면에서 회원가입/로그인을 진행하거나, **게스트로 시작**을 선택하여 즉시 진입한다.
3. 학습 분야와 과목(또는 학습 계획)을 등록한다.
4. 타임 트래커로 학습을 측정하거나 직접 기록을 입력한다.
5. 학습 완료 후 필요시 복습 리마인더에 등록하고, 대시보드에서 누적 현황을 확인한다.

### 5.2 학습 일정 및 복습 관리
1. 사용자가 플래너에 고정 일정(시험 기간, 루틴 등)과 목표일(D-day), 세부 학습 계획을 등록한다.
2. 계획에 맞춰 타임 트래커(`with plan`)로 학습을 진행한다.
3. 설정된 복습 주기에 따라 푸시 알림을 받고, 미완료 시 대시보드와 리마인더 탭에서 누적 색상 경고를 확인하며 복습을 완료 처리한다.

### 5.3 태블릿 분할 화면 학습
1. 사용자가 안드로이드 태블릿에서 필기 앱이나 강의 앱과 함께 Study Tracker를 2분할 또는 3분할(`├`) 화면으로 띄운다.
2. 앱은 할당된 창 크기(`dp`)에 맞춰 레이아웃을 자동 조절한다.
3. 타이머를 실행한 뒤 전체 화면(할당 영역 전체) 시계 모드로 전환하거나, 앱을 백그라운드로 내리고 상단 알림바에서 타이머를 확인하며 공부한다.

### 5.4 계정 연동 및 다중 기기 이용
1. 사용자가 게스트 상태에서 학습 데이터를 기록한다(`guest.db`).
2. 회원가입 또는 로그인을 수행하면 서버로부터 사용자 고유 `UUIDv7`을 부여받고, 기존 데이터를 해당 계정의 로컬 DB(`user_{UUIDv7}.db`)로 이관 및 서버에 백업한다.
3. 다른 기기(예: 스마트폰에서 공부 후 태블릿)에서 동일 계정으로 로그인하여 백업된 학습 데이터를 이어서 사용한다.

## 6. 화면 구성 및 반응형 UI/UX 설계

### 6.0 반응형 브레이크포인트(`dp`) 및 공통 네비게이션 원칙
Android OS가 전달하는 **현재 앱 창에 할당된 논리 픽셀(`dp = px ÷ density`)**을 기준으로 화면을 구성하여 스마트폰, 태블릿 전체 화면, 태블릿 분할 화면(2·3분할) 및 팝업창에 모두 대응한다.

- **화면 폭(`dp`) 기준 분류:**
  - **Compact (`< 600dp`):** 스마트폰 세로 화면, 태블릿 좁은 분할 화면
  - **Medium (`600dp ~ 840dp`):** 스마트폰 가로 화면, 태블릿 세로 화면, 태블릿 1/2 분할 화면
  - **Expanded (`>= 840dp`):** 태블릿 가로 전체 화면, 웹/데스크톱 대화면
- **공통 레이아웃 요소:**
  - **상단 앱 바 (AppBar):** 좌측 뒤로가기(`<`), 우측 유저 프로필 버튼 및 메뉴 버튼(`=` 또는 `⋮`)
  - **우측 메뉴 바 (End Drawer / Menu):** 전체 페이지 이동 및 설정(유저 설정, 대시보드/동기부여 설정) 진입
  - **반응형 네비게이션 바 (택1 활성화):**
    - **하단 네비게이션 바 (`BottomNavigationBar`):** 스마트폰 세로 모드(`Compact`)에서 활성화
    - **좌측 네비게이션 레일 (`NavigationRail` / 확장형 Drawer):** 스마트폰 가로 모드 및 태블릿(`Medium` / `Expanded`)에서 활성화

### 6.1 대시보드 화면 레이아웃
- **최상단:** 동기부여 문구 영역 (1~2줄 높이, 전체 폭 차지)
- **본문 위젯 그리드 (`1x1`, `2x1` 위젯 배치):**
  - **스마트폰 세로:** 앱 바 + 동기부여 배너 + 한 열에 `1x1` 위젯 2개(또는 `2x1` 1개) 배치, 스크롤을 유도하기 위해 하단 위젯 일부가 자연스럽게 걸쳐 보이도록 구성
  - **스마트폰 가로:** 좌측 네비게이션 레일 + 상단 동기부여 배너 + 한 행에 2개 위젯 배치
  - **태블릿 세로 및 분할 화면:** 할당된 `dp`에 따라 한 행에 2~3개의 위젯 및 `2x1` 위젯이 가변적으로 배치
  - **태블릿 가로:** 좌측 네비게이션 레일(버튼으로 폭 확장/축소 가능) + 상단 동기부여 배너 + 한 행에 3~5개의 위젯 배치

### 6.2 세부 기능 페이지 구성
- **로그인 페이지 (`/login`):** `id` 입력, `pw` 입력, 로그인 버튼, 소셜 로그인 버튼, 게스트로 시작 버튼, 회원가입 이동 버튼
- **회원가입 페이지 (`/signup`):** 뒤로가기, `id` 입력, `nick`(닉네임) 입력, `pw` 입력, `cf`(비밀번호 확인) 입력, 회원가입 완료 버튼
- **플래너 페이지:** 기간별 고정 일정 설정, 분야/주제별 할 일(To-do) 및 루틴 관리, D-day 표시
- **타임 트래커 페이지:** 계획 연동/자유 측정 선택, 아날로그(뽀모도로)·디지털(LED) 타이머 뷰, 전체 영역 시계 모드, 직접 시간 입력, 시험 프리셋 모드
- **복습 리마인더 페이지:** 복습 예정 및 지연 누적 목록(단계별 경고 색상), 복습 완료 처리 및 주기 설정
- **설정 페이지:** 계정/프로필 관리 및 동기화 상태 확인, 동기부여 문구 커스터마이징, 앱 테마(라이트/다크/시스템) 및 타이머 기본 설정

## 7. 서비스 정책

### 7.1 오프라인 사용 정책
- 회원가입 및 네트워크 연결 여부와 관계없이 모든 핵심 학습 기능(계획, 타이머, 복습 관리, 대시보드 조회)을 오프라인에서 즉시 이용할 수 있어야 한다.
- 모든 학습 데이터는 기기 내 로컬 SQLite 데이터베이스에 우선 저장된다.

### 7.2 계정 연동 및 단일 기기 다중 사용자 분리 정책
- **파일 단위 로컬 DB 격리:** 비로그인 사용자는 `guest.db`를 사용하고, 로그인한 사용자는 서버에서 발급된 고유 식별자 기반의 **`user_{UUIDv7}.db`** 파일을 개별 생성·사용한다. 이를 통해 학습용 태블릿이나 기기를 타인과 공유하거나 계정을 전환하더라도 로컬 데이터가 섞이거나 노출되지 않는다.
- **게스트 데이터 이관 정책:** 게스트(`guest.db`)로 사용하던 데이터를 최초 회원가입/로그인 시 해당 사용자의 `user_{UUIDv7}.db`로 이관할 수 있도록 지원한다.

### 7.3 백업 및 데이터 일관성 정책
- 백엔드 서버는 클라이언트의 SQLite `.db` 파일 및 백업 메타데이터를 관리하여, 동일 계정으로 스마트폰과 태블릿을 오가며 학습 기록을 이어갈 수 있도록 한다.
- 네트워크 오류 등으로 동기화(백업)가 실패하더라도 기기 내 로컬 SQLite 데이터는 절대 유실되지 않아야 한다.

## 9. 기대 효과

### 9.1 학습 관리 효율성 향상
분산되어 있던 계획, 시간 측정, 복습 알림을 하나의 앱으로 통합하여 학습 현황을 파악하고 기록하는 데 드는 시간과 노력을 줄일 수 있다.

### 9.2 지속적인 학습 습관 형성
대시보드의 시각적 통계 위젯과 미완료 시 쌓이는 누적형 복습 리마인더를 통해 놓치는 과목 없이 꾸준한 학습 습관을 유지할 수 있다.

### 9.3 태블릿 및 멀티 디바이스 학습 환경 최적화
태블릿 분할 화면에 최적화된 반응형 레이아웃과 백그라운드 타이머를 통해 필기 앱·인강 앱과 병행 사용하기 편리하며, 오프라인 지원 및 계정별 DB 백업으로 스마트폰과 태블릿 어디서나 학습을 이어갈 수 있다.
