- 사실 앱 탐색 자체는 큰 의미가 없는게 뭘 가져와도 내가 원하는 그 형태(엑셀 기반 기존 플래너)로 관리할수가 없다
    - 당장 내가 그걸 부르는 명칭마저 제대로 없는 이유가 나 말고 아무도 사용하는 사람을 보지 못 한 커스텀 플래너 형식이기 때문
    - 정사각형 그리드 기반, 각 영역의 크기는 숫자 2개, 문자 1개정도 들어갈 정도
    - 좌측엔 연월월화수목금토일의 9칸 상단엔 분류
        - 좌측 칸과 상단 칸은 고정되어있고 내부 이동
        - 주 단위로 크게 나눌 수도(일반적으로 7칸으로 고정하지 않고 더 길게 한 경우) 있고 7칸을 사용하여 일 단위로 명확하게 표기할 수도 있음
            - 이 때 7칸이 홀수라 과반수로 적용 가능함 (물론 3가지가 있으면 중간게 차지하게)
    - 엑셀 기반이라 불가능했지만 앱에서 가능해야만 하는 기능은 요약
        - 당장은 가로로 길게 펼쳐저 여러 정보를 다룰 때 내가 원하는 부분만 열어 보기가 불가능함
            - 엑셀에서 완전히 불가능한건 아닌데 그건 실시간으로 추가하면서 손쉽게 관리할 방식이 아님

    - 그래서 일반적인 플래너가 아닌 특수 형식의 대시보드가 될 가능성도 있음
